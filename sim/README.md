# Lift-and-clear simulator

`scene.py` builds gravity-enabled Genesis rod scenes.  The clamp welds vertices 0 and 1, fixing a horizontal local tangent; vertex 1 is the effective root.  A trial succeeds when the settled clamp-frame tip droop `delta_tip` is no greater than the absolute failure-plane clearance `h`: `delta_tip <= h`.  The small-deflection prediction is `ell_max ∝ (B_eff*h/w)^(1/4)`.

Raw Genesis `E` is calibrated rather than reported as bending stiffness. `calibrate_beff.py` fixes interval=0.01 m, radius=0.01 m, `G=1e4`, and inextensibility, then fits `delta=w*ell^4/(8*B_eff)`. Genesis `E` is a per-segment discrete stiffness, so continuum `B_eff` legitimately depends on interval; interval is therefore fixed study-wide. Within-interval resolution is accepted only when the measured log-log exponent is in [3.6,4.4]. The root-to-tip arc length is `(tip-root)*interval`; each free vertex is one full `segment_mass` load lump (no endpoint half-lump correction), so `w=(free_vertices*segment_mass)*9.81/ell`. Accepted points require `Pi_g=w*ell^3/B_eff<=0.5`, per-length CV<=5%, and residual<=5%. Tip-slope deviation is recorded as a warning, while two masses verify load invariance.

Calibration and task both use the four-corner-verified stable integrator `dt=2.5e-4, substeps=20` and interval=0.01. The raw-E grid is capped at `[1e6, 3.16e7]` (5 log-spaced points): `E=1e8` is excluded because a stiff+long rod does not settle at this integrator (documented in the manifest). Calibration uses light masses 0.0002 and 0.0004 kg/vertex (small deflection) and reports `w=segment_mass*g/interval`. The measured map is clean and linear, `B_eff ≈ 6.82e-9 * E`, giving `B_eff ∈ [0.0067, 0.215] N·m²` (~1.5 decades ⇒ ~2.4× in predicted `ell_max`), all points CV<2% / residual<4% / exponent≈3.85 / Pi_g≤0.40 / multi-mass invariance ≤4.5%. Fixed-ratio `(cB,cw)` pairs are built in calibrated space and verify boundary invariance along the common-scale line: for `c∈{2,0.5}` the measured `B_eff` ratio, `w` ratio, and `Pi_g` ratio are exactly `c`, `c`, and `1.0` with zero centerline offset. `material.apply_properties` uses Genesis live batched setters and verifies bending-stiffness getter read-back.

Regenerate calibration artifacts with `PYOPENGL_PLATFORM=egl python -m sim.calibrate_beff`; `sim/manifests/calibration_arrays.npz` contains the plotted raw arrays and `calibration.json` contains the metrology manifest.  Run `python -m sim.tasks.lift_and_clear` for serial demo videos.
